# Тестовое задание для Python-разработчика

## Задача

Нужно разработать небольшой backend-сервис для учета задач пользователей.

Сервис должен позволять:

1. Создавать пользователя.
2. Создавать задачу для пользователя.
3. Получать список задач пользователя.
4. Обновлять статус задачи.
5. Удалять задачу.
6. Получать простую статистику по задачам пользователя.

---

## Технические требования

### Стек

Использовать:

- Python 3.11+
- FastAPI
- PostgreSQL или SQLite
- SQLAlchemy / SQLModel / Tortoise ORM — на выбор
- Pydantic
- Pytest
- Docker / Docker Compose

---

## Сущности

### User

Поля:

```text
id
email
name
created_at
```

Требования:

- `email` должен быть уникальным;
- `email` должен валидироваться;
- `name` не должен быть пустым.

---

### Task

Поля:

```text
id
user_id
title
description
status
created_at
updated_at
```

Статусы задачи:

```text
new
in_progress
done
cancelled
```

Требования:

- `title` обязателен;
- `description` опционален;
- `status` по умолчанию `new`;
- задача всегда принадлежит пользователю.

---

## API

### Создать пользователя

```http
POST /users
```

Тело запроса:

```json
{
  "email": "user@example.com",
  "name": "Ivan"
}
```

Пример ответа:

```json
{
  "id": 1,
  "email": "user@example.com",
  "name": "Ivan",
  "created_at": "2026-06-05T12:00:00"
}
```

---

### Получить пользователя

```http
GET /users/{user_id}
```

Если пользователь не найден — вернуть `404`.

---

### Создать задачу

```http
POST /users/{user_id}/tasks
```

Тело запроса:

```json
{
  "title": "Подготовить отчет",
  "description": "Собрать данные за неделю"
}
```

Если пользователь не найден — вернуть `404`.

---

### Получить задачи пользователя

```http
GET /users/{user_id}/tasks
```

Поддержать фильтрацию по статусу:

```http
GET /users/{user_id}/tasks?status=done
```

Поддержать пагинацию:

```http
GET /users/{user_id}/tasks?limit=10&offset=0
```

---

### Обновить статус задачи

```http
PATCH /tasks/{task_id}/status
```

Тело запроса:

```json
{
  "status": "in_progress"
}
```

Если задача не найдена — вернуть `404`.

Если статус некорректный — вернуть `422`.

---

### Удалить задачу

```http
DELETE /tasks/{task_id}
```

Пример ответа:

```json
{
  "ok": true
}
```

---

### Статистика по задачам пользователя

```http
GET /users/{user_id}/tasks/stats
```

Пример ответа:

```json
{
  "total": 10,
  "new": 3,
  "in_progress": 2,
  "done": 4,
  "cancelled": 1
}
```
